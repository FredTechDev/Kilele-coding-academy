# 00 — Orientation & Environment Setup

Welcome to the **Orientation** section of the Kilele Python Learning Pack! Before we write any code, we must set up our digital workshop and understand how computers process instructions.

---

## 🎯 Learning Objectives

By the end of this orientation, you will:
1. Understand what programming is and how Python differs from other languages.
2. Grasp how computers execute instructions from source code to machine execution.
3. Successfully install and verify Python 3 on your operating system (Linux, Windows, or macOS).
4. Install and configure Visual Studio Code with the official Python extension.
5. Confidently open and use the built-in terminal.

## 💡 Recommended Study Sequence

1. Read **`what-is-python.md`** to appreciate why Python is one of the world's most popular first languages.
2. Read **`how-programs-work.md`** to demystify how written text becomes active computer instructions.
3. Follow **`setting-up-python.md`** to install Python 3.8+ on your machine.
4. Follow **`using-vscode.md`** to prepare your editor environment.
5. Once your terminal confirms `python3 --version`, proceed directly to **`../01-getting-started/`**!

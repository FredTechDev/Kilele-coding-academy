# 01 — Getting Started with Python

This section introduces your very first lines of executable code. You will transition from setting up your tools to running Python programs in the terminal.

---

## 🎯 Learning Objectives

By the end of this module, you will:
1. Write and execute your first Python program file (`first-python-program.py`).
2. Use the built-in `print()` function to display text, numbers, and multiple items on the screen.
3. Understand and apply single-line comments (`#`) to document your intentions.
4. Experience how Python reads programs sequentially from top to bottom.
5. Identify common first-time mistakes (like forgetting quotation marks or mistyping function names).

## 🚀 How to Run the Scripts

Open your terminal in this directory and run:

```bash
python3 first-python-program.py
```

Observe the output printed on the console screen. Next, open `print-and-comments.py` in your editor, read the comments, and run it:

```bash
python3 print-and-comments.py
```

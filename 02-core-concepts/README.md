# 02 — Core Concepts

Welcome to the engine room of the **Kilele Python Learning Pack**. This directory contains the complete conceptual building blocks of the Python language. Every file is a standalone, fully runnable lesson script featuring detailed explanations, executable demonstrations, common pitfalls, and hands-on exercises.

---

## 🎯 Learning Sequence

Work through these concepts in order. Each topic directly builds upon the foundations laid by the previous ones:

| # | File | Topic | Key Skills |
| :-: | :--- | :--- | :--- |
| 1 | `variables.py` | Variables & Constants | Assigning identifiers, memory labels, naming conventions (`snake_case`) |
| 2 | `data-types.py` | Python Data Types | Strings (`str`), Integers (`int`), Floats (`float`), Booleans (`bool`) |
| 3 | `user-input.py` | User Input & I/O | Using `input()`, formatting prompts, and stripping whitespace |
| 4 | `type-conversion.py` | Type Casting | Converting between text and numbers safely (`int()`, `float()`, `str()`) |
| 5 | `operators.py` | Operators & Math | Arithmetic (`+`, `-`, `*`, `/`, `//`, `%`), comparisons, and logic |
| 6 | `conditionals.py` | Branching Logic | `if`, `elif`, `else`, compound boolean tests, and edge cases |
| 7 | `for-loops.py` | Definite Loops | `for` loops, `range(start, stop, step)`, accumulator counters |
| 8 | `while-loops.py` | Indefinite Loops | `while` loops, sentinel values, loop guards, `break`, and `continue` |
| 9 | `functions.py` | Modular Functions | `def`, parameters, return values, variable scope, and pure functions |
| 10 | `strings.py` | String Methods | Slicing `[start:stop]`, formatting, and built-in methods (`.replace()`, `.split()`) |
| 11 | `lists.py` | Lists (Dynamic Arrays) | Ordered items, indexing, `.append()`, `.pop()`, slicing, searching |
| 12 | `list-comprehensions.py` | List Comprehensions | Concise mapping & filtering `[expr for item in list if cond]` |
| 13 | `tuples.py` | Tuples (Immutable Data) | Ordered fixed collections, unpacking, and data safety |
| 14 | `dictionaries.py` | Dictionaries (Key-Value) | Mapping keys to values, lookups, `.get()`, updating, and iterating |
| 15 | `sets.py` | Sets (Unique Data) | Deduplication, Venn diagram operations (union, intersection, difference) |
| 16 | `random-module.py` | Randomness & Simulation | `import random`, `randint()`, `choice()`, `shuffle()`, seed basics |
| 17 | `error-handling.py` | Defensive Coding | `try` / `except` blocks, catching errors, resilient input loops |
| 18 | `file-handling.py` | Data Persistence | Reading and writing files using `with open(...)` |
| 19 | `introduction-to-classes.py` | Object-Oriented Intro | Classes, `__init__()`, `self`, methods, `__str__`, and inheritance |

## 💻 How to Study Each File

Each `.py` script in this folder is structured in clear sections:
1. **Concept Definition**: What is this concept and why does it exist?
2. **Syntax Explanation**: Rules, conventions, and grammar.
3. **Runnable Demonstrations**: Run `python3 <filename>.py` to see the outputs in your terminal.
4. **Common Pitfalls & Bugs**: What mistakes beginners frequently make and how to avoid them.
5. **Independent Exercises**: Mini-tasks at the bottom of the file for you to solve!

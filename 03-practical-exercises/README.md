# 03 — Practical Exercises & Assignments

Practice is where theoretical knowledge becomes muscle memory. This directory provides graded problem sets tailored for students in Grades 7–10, spanning three distinct difficulty tiers.

---

## 🎯 The Three Challenge Tiers

```
  [ Level 1: Beginner ]      → Focused on single concepts (Variables, Math, Conditions)
           ↓
  [ Level 2: Intermediate ]  → Combining 2–3 concepts (Loops + Lists + Functions)
           ↓
  [ Level 3: Challenges ]    → Multi-step problem solving & real mini-algorithms
```

### 1. Level 1 — Beginner (`beginner-exercises.md`)
- **Focus:** Direct application of isolated concepts.
- **Topics:** Assigning variables, formatted output, receiving input, basic arithmetic formulas, and simple `if/else` checks.
- **Target:** Building syntax fluency and error-free typing.

### 2. Level 2 — Intermediate (`intermediate-exercises.md`)
- **Focus:** Connecting multiple language concepts together.
- **Topics:** Writing reusable functions, iterating through lists with `for` loops, building `while` validation loops, manipulating strings, and managing dictionaries.
- **Target:** Developing structural logic and algorithmic thinking.

### 3. Level 3 — Programming Challenges (`programming-challenges.md`)
- **Focus:** Independent problem solving and logic puzzles.
- **Topics:** Simulating dice rolls, calculating class statistics, text encryption/decryption (Caesar cipher), inventory trackers, and edge-case validation.
- **Target:** Cultivating self-reliance and engineering perseverance.

---

## 🔑 Solutions

Sample solutions are organized in the [`solutions/`](./solutions/) subfolder.  
**Rule of Thumb:** Attempt every exercise on your own for at least 15 minutes before consulting the solutions. Debugging your own code is where actual programming growth occurs!

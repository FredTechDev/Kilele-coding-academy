## 👩‍🏫 Note for Students and Instructors

- **Self-Directed Learners:** Do not copy-paste answers! Try writing your solution first. If you get stuck for more than 15 minutes, read a few lines of the solution to get unstuck, then close the file and finish the code on your own.
- **Instructors:** These solutions follow standard PEP 8 naming conventions and emphasize code readability over compressed shorthand syntax so they can be shown during classroom reviews.

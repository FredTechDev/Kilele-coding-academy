# 04 — Mini-Projects

Welcome to the **Mini-Projects** gallery! This section bridges the gap between completing isolated exercises and designing complete, standalone software applications.

Each project is an interactive terminal program designed to test and consolidate your programming toolkit.

---

## 🛠 Project Catalog

| # | Project File | Description | Core Concepts Applied |
| :-: | :--- | :--- | :--- |
| 1 | `personal-introduction.py` | Interactive bio generator | Console output, variables, string concatenation, formatted f-strings |
| 2 | `smart-calculator.py` | Command-line math tool | User input, arithmetic operators, branching conditionals, functions |
| 3 | `age-eligibility-checker.py` | Club / event validator | Integer casting, comparison operators, boundary testing, logical `and`/`or` |
| 4 | `number-guessing-game.py` | Classic terminal game | Random number generation (`random.randint`), `while` loops, guess counters |
| 5 | `multiplication-trainer.py` | Math practice drill tool | `for` loops, randomized questions, score tracking, time estimation |
| 6 | `student-performance-checker.py` | Academic grading calculator | Functions with return values, grade boundaries, letter grade assignment |
| 7 | `student-record-manager.py` | In-memory student directory | Lists, dictionaries, CRUD operations (Create, Read, Update, Delete), file saving |
| 8 | `kilele-quiz-game.py` | Interactive trivia challenge | Collections, question dictionaries, loops, score calculation, replay logic |

---

## 🚀 How to Run and Explore

Execute any project directly in your terminal:

```bash
python3 personal-introduction.py
python3 number-guessing-game.py
```

### 🌟 Project Extension Challenges
Once you run and understand each project, challenge yourself to improve it! For example:
- Add high-score tracking.
- Add colorful terminal banners.
- Implement input validation so the program never crashes if a user enters invalid text.

## 🏇 1. Horse Racing Simulation (Primary Capstone)
- **Directory:** [`horse-racing-game/`](./horse-racing-game/)
- **Summary:** An interactive, terminal-based animated horse race with a simulated classroom credit betting economy.
- **Key Concepts:**
  - Random movement simulation with `random.randint()`.
  - Frame-based animation with screen clears (`os.system`) and pacing (`time.sleep`).
  - Player balance tracking with virtual classroom tokens.
  - Multi-horse state tracking using dictionary structures.
  - Comprehensive input validation ensuring zero crash scenarios.

## 📊 2. Student Results Management System
- **Directory:** [`student-results-system/`](./student-results-system/)
- **Summary:** A database-style terminal utility for recording subject marks, calculating weighted averages, ranking performers, and producing academic report cards.
- **Key Concepts:**
  - Nested dictionary and list architectures.
  - Statistical calculations (mean, median, top score, lowest score).
  - Exporting formatted text and CSV reports to disk.

---

## 🏫 3. School Management System
- **Directory:** [`school-management-system/`](./school-management-system/)
- **Summary:** An introductory object-oriented management system modeling Students, Teachers, Classrooms, and Courses.
- **Key Concepts:**
  - Object-Oriented Programming (Classes, instances, methods, encapsulation).
  - Persistent state storage with JSON (`json.dump` / `json.load`).
  - Interactive multi-level terminal navigation menus.

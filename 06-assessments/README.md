# 06 — Assessments & Evaluation

Assessment in the **Kilele Python Learning Pack** is designed to measure conceptual comprehension, problem-solving independence, and the ability to diagnose and explain code.

---

## 📋 Assessment Framework

The assessment suite is split into four milestone evaluations corresponding to the curriculum phases:

| Assessment File | Coverage | Target Competency |
| :--- | :--- | :--- |
| `fundamentals-assessment.md` | Modules 01–04 | Syntax, `print()`, variables, data types, casting, user input |
| `control-flow-assessment.md` | Modules 05–07 | Operators, expressions, `if`/`elif`/`else`, `for` & `while` loops |
| `functions-and-data-assessment.md` | Modules 08–10 | Functions, parameters, return values, scope, lists, dicts, `random` |
| `final-practical-assessment.md` | Modules 11–14 | Error handling, file I/O, classes, modular program design & capstones |

---

## 🎯 Evaluation Dimensions

Each assessment combines multiple evaluation methods:
1. **Multiple Choice & Syntax Spotting:** Quick diagnostic checks to catch common misunderstandings.
2. **Code Reading & Output Tracing:** Predicting what a code snippet prints without running it.
3. **Bug Hunting:** Identifying logical and runtime flaws in pre-written broken code.
4. **Live Programming Task:** Writing a functional script from scratch against formal user requirements.
5. **Code Explanation (Viva Voce):** Asking the student to articulate *why* their program was structured in a specific way.

---

## 🧭 Instructions for Students & Educators
- **Students:** Read the problem statements carefully. Write clean, formatted code with comments explaining your reasoning.
- **Instructors:** Detailed marking criteria and rubrics can be found in [`../07-teacher-resources/marking-guide.md`](../07-teacher-resources/marking-guide.md).

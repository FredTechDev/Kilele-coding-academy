## 👩‍🏫 Core Teaching Philosophy

1. **Code with Them, Not at Them:** Live-code demonstrations from a blank editor rather than only showing finished slides. Let students see you make and fix real syntax typos.
2. **Predict Before Running:** Before running any demo code, pause and ask the class: *"What will appear in the terminal when I press enter?"*
3. **Praise the Debugging Process:** Celebrate logical thinking and systematic bug hunting rather than just getting the right answer quickly on the first try.
4. **Gradual Release of Responsibility:** Follow the `I Do` (Teacher demo) → `We Do` (Guided classroom practice) → `You Do` (Independent exercise) progression.
